# Workspace clarity — Phase 2

Issue: https://github.com/dhjh24/openterminal/issues/13

## Problem (before)

Mission Control led with a dense Launch Matrix of seven equal-weight groups and dozens of cards. Primary trading/portfolio actions competed with advanced destinations, so the first useful next step was unclear—especially on phone viewports.

## Change

- Five priority Home sections: **Market now**, **Your desk**, **Action queue**, **Portfolio snapshot**, **Explore all tools**
- Full categorized launcher moved into an Explore dialog/sheet (routes unchanged)
- Recent screens + action-queue states for alerts, stale quotes, backtests, paper, and empty portfolio
- Header primary actions trimmed to workspace CTA + Explore
